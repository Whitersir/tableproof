# 表有据 · TableProof v0.2.1

首个带正式项目名称与源码附件的公开预览版。采用 MIT 许可证。

## 项目介绍

表有据是一个本地表格核对与报告工作台，面向活动报名、签到和小团队名单核对。普通程序负责精确匹配与计算，可选模型负责理解自然语言要求、提出方案和选择工具；用户审阅后再执行。

## 本版功能

- CSV 单字段/复合字段匹配、筛选与分组统计。
- 重复、空标识、冲突和未报名签到检查，结果追溯到源记录。
- 自带模型 API 的本机设置，显式连接与工具调用测试。
- Agent 执行前方案审阅、补充说明、工具校验、轮数限制和错误记录。
- Markdown 报告、三类 CSV、SQLite 历史。

## 下载与启动

下载附件 **TableProof-v0.2.1-source.zip** 并解压。这是源码包，需要 Python 3.11+，不包含 EXE 或虚拟环境。

Windows，在解压后的目录运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

Linux / macOS：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run.py
```

打开 http://127.0.0.1:8765，点击“载入示例并核对”。预期：有效报名 6、到场 4、未到场 2、到场率 66.67%。该流程无需 API。

## 验证与边界

本地已通过 72 项自动测试、12 个确定性业务场景、12 组浏览器检查，以及本机模拟 HTTP 接口的端到端检查。具体结果见仓库 evaluations/checks.json；线上 CI 状态见仓库 Actions。

真实中转站模型仍待联调；没有宣称模型成功率或真实用户效率提升。当前适用于本地单用户，支持 CSV 与精确匹配，暂不支持 Excel 直接导入、日期区间或公网多人服务。

源码包不包含 API Key、.env、用户上传文件、数据库和运行日志。SHA256SUMS.txt 用于核对源码包完整性。
