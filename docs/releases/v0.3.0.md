# 表有据 · TableProof v0.3.0 — 人工补签

本版增加人工补签，并更新项目说明、界面截图与源码附件。保留既有 CSV 核对、模型设置和 Agent 方案审阅功能。

## 新增功能

- 完成核对后，在签到区域或结果区点击“补签登记”。
- 按学号、姓名或班级搜索完整未到场名单，不受 200 条页面预览限制。
- 选择人员，填写实际签到时间和原因，确认其实际参加了当前统计范围内的活动。
- 保存后更新到场人数、未到场人数、分组和到场率；提供独立补签记录 CSV。
- 补签生成新的结果快照，原始上传文件和补签前历史不会被覆盖。
- 同一操作重复提交只生成一次；已到场、空标识、冲突与范围外人员不能直接补签。

补签仅作用于当前任务及其后续派生结果。重新运行原始表格不会自动带入其他任务的补签。

## 下载与启动

下载附件 **TableProof-v0.3.0-source.zip** 并解压，需要 Python 3.11+。这是源码包，不是 EXE。

Windows：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

Linux / macOS：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run.py
```

打开 http://127.0.0.1:8765，载入示例。补签前为有效报名 6、到场 4、未到场 2、到场率 66.67%；为 004 补签后为到场 5、未到场 1、到场率 83.33%。

## 验证与边界

自动测试覆盖补签统计、导出、持久化、历史隔离、重复与并发重试、非法标识和时间等场景；浏览器检查包含真实表单提交、补签下载和刷新后恢复。确切数量见 evaluations/checks.json 与本次提交的 Actions。

真实模型仍未联调，本次补签无需模型调用。适用于本地单用户。源码包不包含密钥、用户上传、数据库或虚拟环境，附 SHA256SUMS.txt 供校验。
