# 界面设计决定

对象：第一次使用核对工具的活动组织者。页面只承担一件事：导入两表，核对，检查并下载结果。

使用 UI/UX Pro Max 与 frontend-design 的指导做了两个设计检索。检索得到的通用营销页面结构不适合本项目，因此未采用 Hero/CTA、客户标志等建议。保留了数据工具的表格优先、可见焦点、错误反馈和响应式原则。

v0.2 根据用户对模板感的反馈，改为文件工作台。配色：文字 `#24292e`、低饱和操作绿 `#15634e`、底色 `#f4f5f5`、纸白 `#ffffff`、分隔线 `#d9dddf`、异常色 `#805219`。取消大幅宣传标题、彩色指标卡、圆点时间线和大圆角，颜色只用于操作和状态。

文字：本机 Segoe UI / 微软雅黑承载正文，Consolas 承载数字和记录。没有在线字体或图标 CDN 依赖。字号和颜色以核对长表时可读为目标。

布局：左侧按真实步骤导入和设定，右侧先显示统计，再显示表格与来源。手机上改为单列。匹配字段之间的双向箭头表达“两边字段必须对应”。模型设置使用原生 dialog，具备浏览器原生焦点约束和 Esc 关闭；执行方案以字段清单展示，不添加无关插图或动画。

构建前评审：删掉通用营销建议，选择真实任务工作区；保留一处强调——两表字段映射。构建后使用 Edge 截图检查桌面、手机布局，并验证四个断点没有页面横向溢出。长表允许在自己的表格区域横向滚动。
